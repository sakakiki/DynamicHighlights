# アンケート案

この資料は、実験で参加者に答えてもらうアンケートの案です。
元にした研究（新宮 2025「パノラマ360度画像のHMD視聴における視線方向制御による見どころ鑑賞の効率化」）と結果を比べられるように、元研究の項目と7段階の尺度をできるだけそのまま使っています。
記入は紙か Google フォームなどで行います（Unity のシステムには入れていません）。

---

## 1. 目的

本研究の新手法（動的制御）は、頭の角速度 ω に応じて見どころ範囲内の傾き s を変えます。

- **速く回すとき**：元研究と同じ強さで制御する（s = s₀ = 0.55）。見どころに素早く向けて、見どころで止まりやすくする。
- **ゆっくり見るとき・止まっているとき**：制御を弱める（s → 1）。見どころ以外を見たいときに、制御が邪魔にならないようにする。

元研究の評価2（実写の360度画像）の自由記述では、次の意見が出ていました。新手法は、ここを改善することをねらっています。

- 見どころ以外を見ようとしたときに見づらくなった
- 見どころ付近で首を左右に往復させると不快感があった

そこでアンケートでは、次の3点を確かめます。

1. 見どころの見やすさや、見どころへ素早く向けられることが、元研究の手法（制御一定）と同じくらい保たれているか
2. 見どころ以外の見やすさが、制御一定より良くなっているか
3. 酔い・不快感・違和感が、制御一定より少ないか

## 2. 実施の流れ

| タイミング | 答えてもらう内容 |
|---|---|
| 実験の前 | 参加者の属性（3章の「事前アンケート」） |
| 練習試行の後 | なし（操作に慣れてもらうだけ） |
| 本番の各条件の直後（3回） | 項目1〜6（7段階）と自由記述。HMD を外してから答えてもらう（使い方ガイド 5.3 の手順7） |
| 全条件の後 | 3条件の順位づけと、全体の自由記述 |

**実施上の注意**

- 項目1〜3は「見どころ」という言葉を使うので、実験の前に **どれが見どころかを伝えます**（一番大きな黄色い塔。使い方ガイド 5.2 の説明文に入れてあります）。元研究でも、見どころのオブジェクトは参加者に分かる状態でした。
- 条件の名前（「通常」「制御一定」「動的制御」）は参加者に伝えません。「1回目・2回目・3回目」と呼びます。
- 条件の順番は、被験者IDに応じて自動で入れ替わります（使い方ガイド 5.5）。回答用紙には、何回目の条件かを書いておき、どの条件だったかは実験者が実験者パネルの表示を見て記録します。
- 急に止まったときに景色が少し戻る動き（解説資料 4章の既知の挙動）は、実験の前に全員へ同じ言い方で説明します（使い方ガイド 5.2）。項目6は、この説明を聞いたうえで答えてもらいます。どの条件で起きやすいかは伝えません。
- 研究の仮説（どの条件が良いはずか）は伝えません。

## 4. 各条件の後に答える項目（7段階）

すべての項目で、**数字が大きいほど良い** 向きにそろえています（元研究と同じ）。

### 項目の一覧

| No. | 項目 | 出典 | 確かめること |
|---|---|---|---|
| 1 | 見どころに視線を向けるまでの操作を、素早く行えたと感じたか | 元研究 評価1-1 の第1項目（表 3.1） | 見どころへの視線移動の促進 |
| 2 | 見どころが見やすかったか（見どころの中心に視線を合わせやすかったか） | 元研究 評価1-1 の第2項目（表 3.2） | 見どころでの視線移動の抑制 |
| 3 | 見どころ以外の物を見たいときに、思いどおりに見られたか | 本研究で追加 | **新手法のいちばんの検証項目**（制御が邪魔にならないか） |
| 4 | 酔いを感じなかったか | 元研究 評価1-1 の第4項目（表 3.4） | 酔い |
| 5 | 不快感や違和感を感じなかったか | 元研究 評価2（表 3.6、5段階）を7段階にしたもの | 不快感・違和感 |
| 6 | 頭を止めたときに、視界が勝手に動くと感じなかったか | 本研究で追加 | 急停止の戻り（既知の挙動）の影響 |

**元研究の第3項目（「見どころ範囲を超えて視線が行き過ぎてしまうことはなかったか」）は外します。**
元研究の評価1-1では、どの条件でも平均が 6.5〜7 に集まり、条件による差が出ませんでした（3.2.4節）。そのため評価1-2でも外されています（3.2.5節）。

**元研究との回答の形の違い**：元研究の評価1は、「直前に体験した基準条件（制御なし）と比べてどうだったか」を答える形でした。
本研究では、通常の VR 視聴も3条件のうちの1つで、順番も入れ替わります。そのため、**各条件をそれぞれ単独で評価してもらう** 形にします。
数値をそのまま元研究と比べることはできないので、元研究との比較は「条件の間の差の向き」で行います。

### 自由記述（各条件の後）

答えを誘導しないように、良い点と悪い点の両方を聞きます。

- 見やすかった場面、見にくかった場面があれば教えてください。
- 気になった動きや、思いどおりにならなかったことがあれば教えてください。
- そのほか、気づいたことがあれば自由に書いてください。

## 6. 集計と分析の方法（案）

| 手順 | 内容 |
|---|---|
| ① 平均・中央値 | 項目ごと・条件ごとに、平均値と中央値を出す。元研究と同じくグラフは平均値で描き、中央値も併記する |
| ② 条件の差の検定 | 同じ参加者が3条件すべてに答える（参加者内比較）、かつ回答は順序のある段階評価なので、**フリードマン検定** で3条件に差があるかを調べる |
| ③ どの条件の間に差があるか | ② で差があれば、**ウィルコクソンの符号順位検定** で2条件ずつ比べる。3回比べるので、ホルム法などで多重比較の補正をする |
| ④ 順位づけ | 各観点で、条件ごとの平均順位を出す（フリードマン検定も使える） |
| ⑤ 自由記述 | 似た意見をまとめて分類し、条件ごとに数える（例：「見どころ以外が見づらい」と書いた人数） |

**特に見たい比較**：動的制御と制御一定の差（項目2・3・5・6）。

- 項目2（見どころの見やすさ）では、差が小さければよい（効果が保たれている）。
- 項目3・5では、動的制御のほうが高ければ、新手法の効果があったと言える。
- 項目6では、動的制御だけが低い（視界が動くと感じる）かどうかで、急停止の戻りの影響を確認する。

## 7. CSV との対応（主観と客観の比べ方）

アンケート（主観）の結果を、システムが記録した CSV（客観）で裏付けられます。
CSV の列の意味は「使い方ガイド」の 6章を見てください。

| アンケート項目 | 裏付けに使う CSV の値 | 見方の例 |
|---|---|---|
| 1（素早さ） | `*_summary.csv` の `Highlight` 行の `first_reach_s` | 見どころに初めて視線が届いた時刻。小さいほど素早い |
| 2（見どころの見やすさ） | `*_summary.csv` の `Highlight` 行の `dwell_s` | 見どころを見ていた合計時間 |
| 3（見どころ以外） | `*_summary.csv` の `Before`・`After` 行の `first_reach_s`・`dwell_s` | 手前・過ぎた方向のオブジェクトにどれだけ早く・長く視線を向けられたか |
| 4・5・6（酔い・不快感・視界が勝手に動く） | `*_frames.csv` の `omega_deg_per_s`・`s`・`c` | 速く回してから急に止まった回数（ω が大きい状態から 0 近くに下がった回数）など |
| 動的制御が意図どおり働いたかの確認 | `*_frames.csv` の `s`・`c` | 動的制御の試行で、s が 0.55〜1 の間で変化しているか |
| 文字の読み上げの照合 | `*_summary.csv` の `label` | 実験者が記録した読み上げの内容と照合する |

視線方向は、元研究と同じく **頭の向き** で判定しています（眼球の動きは測っていません）。
「見ていた」とする判定は、視野の中心から `gazeAngleThreshold`（初期値 10°）以内です。
