# 角速度 ω の計算：指数重み付き平均（スライド7の式）アーカイブ

このフォルダには、**使わないことにした角速度の計算方法** のコードを保管しています。
`Assets/` の外にあるので、Unity はこのフォルダの `.cs` ファイルを読み込みません。

## 変更した理由（2026-11-24）

元研究のプロジェクト（360-Image）を調べたところ、HMD の角速度は SteamVR の `VelocityEstimator` で求めていました。
その計算方法は「直近5フレームの角速度の **単純平均**」です。
本研究も元研究と同じ方法に合わせるため、スライド7の指数重み付き平均をやめて、単純平均に変更しました。

## 保管している計算方法（スライド7の式）

```
v_k = (r_{k−1} − r_k) / Δt_k              … 区間 k の角速度
w_k = Δt_k · e^(−a_k / τ)                 … 区間 k の重み（a_k：区間の中間時刻から現在までの時間）
ω   = Σ(w_k · v_k) / Σ w_k   （k = 1〜N）  … 重み付き平均
```

新しいフレームほど重く（時定数 τ）、長いフレームほど重く（Δt_k）なる平均です。
パラメータは N = 5、τ = 0.05 秒でした。

## いまの計算方法（単純平均）との違い

| | 指数重み付き平均（このフォルダ） | 単純平均（いまの実装） |
|---|---|---|
| 式 | ω = Σ(w_k · v_k) / Σ w_k | ω = (1/M) · Σ v_k（M = min(計測回数, N)） |
| 重み | 新しい・長いフレームほど重い | すべて同じ |
| パラメータ | N、τ | N だけ |
| 頭が止まってから ω = 0 になるまで | 0 には近づくが、ちょうど 0 にはならない（直近 N フレームが全部 0 になるまでは少し残る） | ちょうど N フレーム後に 0 |
