# アンケート案

この資料は、実験で参加者に答えてもらうアンケートの案です。
元にした研究（新宮 2025「パノラマ360度画像のHMD視聴における視線方向制御による見どころ鑑賞の効率化」）と結果を比べられるように、元研究の項目と7段階の尺度をできるだけそのまま使っています。
記入は紙か Google フォームなどで行います（Unity のシステムには入れていません）。

---

## 1. 目的

本研究の新手法（動的制御）は、頭の角速度 ω に応じて見どころ範囲内の傾き s を変えます。

- **速く回すとき**：元研究と同じ強さで制御する（s = s₀ = 0.55）。見どころに素早く向けて、見どころで止まりやすくする。
- **ゆっくり見るとき・止まっているとき**：制御を弱める（s → 1）。見どころ以外を見たいときに、制御が邪魔にならないようにする。

元研究の評価2（実写の360度画像）の自由記述では、次の意見が出ていました。新手法は、ここを改善することをねらっています。

- 見どころ以外を見ようとしたときに見づらくなった
- 見どころ付近で首を左右に往復させると不快感があった

そこで実験では、参加者の **意図（何を見ようとしているか）** ごとに試行を3つのパターンに分け、パターンごとに3条件を比べます。

| パターン | 見てもらう物 | 確かめること |
|---|---|---|
| 見どころの鑑賞 | 見どころ（黄色い塔、45°） | 見どころの見やすさ・素早さが、元研究の手法（制御一定）と同じくらい保たれているか |
| 見どころより手前の鑑賞 | 青い箱（30°。見どころは 60°） | 見どころより手前の物を見たいときに、制御が邪魔にならないか（促進の区間で行き過ぎないか） |
| 見どころより奥の鑑賞 | 青い箱（60°。見どころは 30°） | 見どころを通り過ぎて奥の物を見たいときに、制御が邪魔にならないか（抑制の区間で引き止められないか） |

酔い・不快感・違和感が制御一定より少ないかも、すべてのパターンで確かめます。

## 2. 実施の流れ

実験は「練習（3試行）→ 本番 9セット」です。1セットは、同じパターン・同じ条件で右左交互に 6 試行です。
パターンごとに3条件（3セット）を続けて行います（使い方ガイド 5.5）。

| タイミング | 答えてもらう内容 |
|---|---|
| 実験の前 | 参加者の属性（3章の「事前アンケート」） |
| 練習の後 | なし（操作に慣れてもらうだけ） |
| 各セットの直後（9回） | 項目1〜6（7段階）と自由記述。HMD を外してから答えてもらう（使い方ガイド 5.3 の手順7） |
| 各パターンの3セットが終わった後（3回） | そのパターンの3セットの順位づけ（5章） |
| 全セットの後 | 全体の自由記述 |

**実施上の注意**

- 実験の前に、**見どころ（大きな黄色い塔）と青い箱** を伝えます（使い方ガイド 5.2 の説明文に入れてあります）。
- 条件の名前（「通常」「制御一定」「動的制御」）は参加者に伝えません。パターンの中で「1回目・2回目・3回目」と呼びます。
- 回答用紙には、実験者がセット番号・パターン・条件を書いておきます（実験者パネルに表示されます）。
- 急に止まったときに景色が少し戻る動き（解説資料 4章の既知の挙動）は、実験の前に全員へ同じ言い方で説明します（使い方ガイド 5.2）。項目6は、この説明を聞いたうえで答えてもらいます。どの条件で起きやすいかは伝えません。
- 研究の仮説（どの条件が良いはずか）は伝えません。
- 9セットあるので、アンケートの時間を休憩も兼ねるようにし、酔いや疲れが強いときは無理に続けないでください。

## 4. 各セットの後に答える項目（7段階）

すべての項目で、**数字が大きいほど良い** 向きにそろえています（元研究と同じ）。
項目1〜3の「〇〇」には、そのセットで見た物が入ります（見どころの鑑賞なら「見どころ（黄色い塔）」、手前・奥の鑑賞なら「青い箱」）。
こうすると、すべてのセットで同じ項目になるので、パターンどうしでも比べられます。

### 項目の一覧

| No. | 項目 | 出典 | 確かめること |
|---|---|---|---|
| 1 | 〇〇に視線を向けるまでの操作を、素早く行えたと感じたか | 元研究 評価1-1 の第1項目（表 3.1）の「見どころ範囲」を「〇〇」にしたもの | 視線移動の速さ（促進） |
| 2 | 〇〇が見やすかったか（〇〇の中心に視線を合わせやすかったか） | 元研究 評価1-1 の第2項目（表 3.2） | 対象の見やすさ |
| 3 | 〇〇に向けて、思いどおりに視線を動かせたか（行き過ぎたり、届きにくかったりしなかったか） | 本研究で追加 | **新手法のいちばんの検証項目**（制御が邪魔にならないか）。手前の鑑賞では行き過ぎ、奥の鑑賞では引き止められる感じを拾う |
| 4 | 酔いを感じなかったか | 元研究 評価1-1 の第4項目（表 3.4） | 酔い |
| 5 | 不快感や違和感を感じなかったか | 元研究 評価2（表 3.6、5段階）を7段階にしたもの | 不快感・違和感 |
| 6 | 頭を止めたときに、視界が勝手に動くと感じなかったか | 本研究で追加 | 急停止の戻り（既知の挙動）の影響 |

**元研究の第3項目（「見どころ範囲を超えて視線が行き過ぎてしまうことはなかったか」）は、そのままの形では使いません。**
元研究の評価1-1では、どの条件でも平均が 6.5〜7 に集まり、条件による差が出ませんでした（3.2.4節）。そのため評価1-2でも外されています（3.2.5節）。
本研究では、見どころ以外の物を見るパターンで「行き過ぎ」や「届きにくさ」が起きうるので、項目3として形を変えて聞きます。

**元研究との回答の形の違い**：元研究の評価1は、「直前に体験した基準条件（制御なし）と比べてどうだったか」を答える形でした。
本研究では、通常の VR 視聴も3条件のうちの1つで、順番も入れ替わります。そのため、**各セットをそれぞれ単独で評価してもらう** 形にします。
数値をそのまま元研究と比べることはできないので、元研究との比較は「条件の間の差の向き」で行います。

## 5. 各パターンの後の順位づけ

パターンの3セット（「1回目・2回目・3回目」）が終わったら、そのパターンについて順位（1位〜3位）をつけてもらいます。同じ順位は付けないでもらいます。
記憶が新しいうちに答えてもらうため、パターンごとに聞きます（全部終わってからまとめて聞くと、最初のパターンを思い出しにくいため）。

|---|---|---|---|

| もう一度使いたいと思う順 | | | |

- 見え方の違いに気づいたら教えてください。

## 6. 集計と分析の方法（案）

| 手順 | 内容 |
|---|---|
| ① 平均・中央値 | 項目ごと・**パターン × 条件** ごとに、平均値と中央値を出す。元研究と同じくグラフは平均値で描き、中央値も併記する |
| ② 条件の差の検定 | パターンごとに、同じ参加者が3条件すべてに答える（参加者内比較）、かつ回答は順序のある段階評価なので、**フリードマン検定** で3条件に差があるかを調べる |
| ③ どの条件の間に差があるか | ② で差があれば、**ウィルコクソンの符号順位検定** で2条件ずつ比べる。3回比べるので、ホルム法などで多重比較の補正をする |
| ④ 順位づけ | パターンごとに、条件ごとの平均順位を出す（フリードマン検定も使える） |
| ⑤ 自由記述 | 似た意見をまとめて分類し、パターン × 条件ごとに数える（例：「行き過ぎた」と書いた人数） |

**特に見たい比較**：動的制御と制御一定の差。

| パターン | 期待される結果 |
|---|---|
| 見どころの鑑賞 | 項目1・2の差が小さい（見どころの鑑賞の効果が保たれている） |
| 見どころより手前の鑑賞 | 項目2・3で動的制御のほうが高い（促進の区間での行き過ぎが減る） |
| 見どころより奥の鑑賞 | 項目1・3で動的制御のほうが高い（見どころでの引き止めが弱まる） |
| すべて | 項目4・5で動的制御のほうが高い（酔い・不快感が少ない）。項目6で動的制御だけ低くないか（急停止の戻りの影響） |

## 7. CSV との対応（主観と客観の比べ方）

アンケート（主観）の結果を、システムが記録した CSV（客観）で裏付けられます。
CSV の列の意味は「使い方ガイド」の 6章を見てください。
まとめファイル（`*_summary.csv`）では、**`is_intended = 1` の行**（その試行で見てもらった物）を、`pattern` と `condition` ごとに集計すると、アンケートのセットと同じ単位になります。

| アンケート項目 | 裏付けに使う CSV の値 | 見方の例 |
|---|---|---|
| 1（素早さ） | `*_summary.csv` の `is_intended = 1` の行の `first_reach_s` | 対象に初めて視線が届いた時刻。小さいほど素早い |
| 2（見やすさ） | 同じ行の `dwell_s` | 対象を見ていた合計時間 |
| 3（思いどおりに動かせたか） | `*_frames.csv` の `v_deg` と、対象の角度（`*_summary.csv` の `object_yaw_deg` / `highlight_yaw_deg`） | 対象を行き過ぎた最大の角度、対象の付近で v が行ったり来たりした回数など |
| 3（奥の鑑賞での引き止め） | 手前・奥の鑑賞の `is_intended = 0`（見どころ）の行の `dwell_s` | 見どころに視線が留まってしまった時間 |
| 4・5・6（酔い・不快感・視界が勝手に動く） | `*_frames.csv` の `omega_deg_per_s`・`s`・`c` | 速く回してから急に止まった回数（ω が大きい状態から 0 近くに下がった回数）など |
| 動的制御が意図どおり働いたかの確認 | `*_frames.csv` の `s`・`c` | 動的制御の試行で、s が 0.55〜1 の間で変化しているか |
| 文字の読み上げの照合 | `*_summary.csv` の `label` | 実験者が記録した読み上げの内容と照合する |

視線方向は、元研究と同じく **頭の向き** で判定しています（眼球の動きは測っていません）。
「見ていた」とする判定は、視野の中心から `gazeAngleThreshold`（初期値 10°）以内です。
